# SAPR-BAR Web

Основа независимой веб-версии SAPR-BAR для плоских стержневых конструкций. Приложение открывает, проверяет и сохраняет типизированную модель проекта и выполняет линейный статический расчёт рамными элементами Эйлера—Бернулли.

## Требования

- Node.js 22 LTS или новее;
- npm 10 или новее;
- современный браузер.

Приложение работает в браузере и не требует backend или базы данных.

## Требования для разработки

- Node.js 22 LTS или новее;
- npm 10 или новее;
- современный браузер.

## Запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения. Встроенная портальная рама загружается автоматически.

## Работа в редакторе

Верхняя панель переключает выбор, создание узлов и элементов и перемещение вида. Колесо мыши меняет масштаб; координаты выбранного узла, свойства элемента, опоры и нагрузки редактируются справа. Сетка и привязка включаются отдельно, изменения поддерживают отмену и повтор.

После корректного расчёта в нижней области доступны таблицы перемещений, реакций и концевых усилий, а на схеме — деформированная форма и эпюры `N/Q/M`. Масштаб деформаций, единицы и правила знаков показаны рядом с результатами. После любого изменения модели старые результаты явно помечаются как неактуальные и не отображаются на схеме до повторного расчёта.

Кнопка «Редактор CN/LD/MD» открывает три текстовых редактора. Можно загрузить, создать с нуля или из синтетического B/R-примера, изменить и отдельно скачать каждый файл. Импорт понимает подтверждённое оформление настоящего B-комплекта: служебные `*`-строки, метки `=NN`, пустые резервные записи и CRLF; вход декодируется как CP866. Проверка всего комплекта требует выбрать вариант HELP_30B/R и исходную систему единиц, затем показывает отчёт до применения. Неподдерживаемые воздействия не игнорируются. После применения исходные тексты сохраняются в JSON и вновь открываются в legacy-редакторе.

Кнопка «Печать» формирует браузерный печатный отчёт со схемой, исходными данными, нагрузками, допущениями, актуальными результатами и версией ядра. Сохранение современного проекта остаётся основным способом обмена данными.

## Проверенные возможности

- типизированное открытие, валидация и сохранение `.saprbar.json` версии `1.0.0`;
- создание и редактирование плоской стержневой схемы, опор, концевых шарниров, материалов, сечений и реализованных нагрузок;
- настоящий линейно-статический расчёт рам Эйлера—Бернулли, реакции, перемещения, `N/Q/M`, напряжения и деформированная схема;
- аналитически восстановленный прогиб по длине элемента при равномерной нагрузке; применяется линейная модель Эйлера—Бернулли без сдвиговой деформации;
- явный отказ для механизмов, сингулярных и несовместимых моделей;
- пометка результатов как неактуальных после изменения модели;
- создание, текстовое редактирование, проверка и скачивание CN/LD/MD в документированном синтетическом профиле, предварительный отчёт импорта и печатный отчёт.

Математическое ядро покрыто аналитическими unit-тестами; типы, тесты и production-сборка запускаются `npm run check`. Отображаемую точность можно выбрать от 0 до 12 знаков; расчёт и JSON не округляются. Фактические результаты текущего прогона и ограничения браузерной проверки зафиксированы в [docs/status.md](docs/status.md).

## Формат проекта

Проект сохраняется в UTF-8 JSON с рекомендуемым расширением `.saprbar.json`. Текущая версия схемы — `1.0.0`; значения расчётной модели хранятся в SI. При открытии приложение сначала проверяет структуру, версию, числа, ссылки и совместимость поддерживаемого подмножества. Ошибочный файл не заменяет открытую модель.

Пример: [tests/fixtures/portal-frame.saprbar.json](tests/fixtures/portal-frame.saprbar.json).

Основные типы находятся в `src/model/types.ts`, семантическая проверка — в `src/model/validation.ts`, безопасное чтение/запись — в `src/model/projectFormat.ts`. Эти модули не зависят от React.

## Поддерживаемая модель данных

- двумерные узлы;
- рамные стержни с материалом, сечением и концевыми освобождениями вращения;
- материалы с модулем Юнга;
- сечения с `A`, `Iz`, `y−`, `y+` и исходной геометрией;
- закрепления `Ux`, `Uy`, `Rz`;
- узловые `Fx`, `Fy`, `Mz`;
- равномерные стержневые нагрузки `qx`, `qy` в локальных осях;
- одно линейно-статическое загружение и параметры будущего решателя.

Подробные границы приведены в [docs/spec.md](docs/spec.md), текущий статус — в [docs/status.md](docs/status.md).

## Расчётное ядро и ограничения

Реализованы сборка глобальной системы, нулевые закрепления, концевые освобождения вращения, узловые и равномерные локальные нагрузки, перемещения, реакции и внутренние `N/Q/M` с нормальными напряжениями. Механизм или численная вырожденность возвращают явный отказ.

Математика и знаки описаны в [docs/solver-theory.md](docs/solver-theory.md), аналитические проверки — в [docs/solver-verification.md](docs/solver-verification.md). Совместимость с вычислительным алгоритмом DOS SAPR-BAR не заявляется.

Не поддерживаются геометрическая/физическая нелинейность, устойчивость, собственные и вынужденные колебания, динамика, комбинации загружений, температура, собственный вес, пружины и заданные перемещения. Импорт B проверен на настоящем комплекте `GOLOBORO.CN/LD/MD`, рассчитанном SAPR-BAR 3.0. Скачивание текста пока не подтверждает обратное чтение DOS-программой: экспорт CP866 и точное воспроизведение шаблонов не верифицированы. Вариант R проверен только синтетически. Автоматический legacy-экспорт современной графической модели отсутствует.

## Точность чисел и краткая РГР

В панели инструментов и диалоге «Отчёт РГР» есть настройка «Знаков после
запятой» (0–12, по умолчанию 3). Она меняет таблицы, подписи эпюр, предпросмотр,
HTML и печать без пересчёта. Десятичный разделитель — запятая. Точный ноль
показывается как 0; малые ненулевые значения — в научной записи. Для площадей
в м² и инерций в м⁴ используется научная запись с выбранной точностью мантиссы.
Поля ввода, расчётные значения и JSON не округляются этой настройкой.

После актуального расчёта откройте «Отчёт РГР» и выберите «Краткая РГР».
Последовательность: Дано → реакции и усилия → площади → напряжения →
деформации → перемещения → проверка жёсткости → итог. Формулы сопровождаются
численной подстановкой и единицами. Поддержаны одна и несколько осевых
заделок; при нескольких сначала выводятся равновесие и совместность.
Переключатель «Включить схему и эпюры» добавляет схему и только N, σ, u.

«Подбор площадей» указывается лишь после команды «Подобрать A₀ по прочности».
При ручных площадях показывается проверка, требуемые и принятые площади
разделены. Результат подбора сохраняется в необязательном metadata.areaSizing;
изменение расчётных данных или допускаемых напряжений отменяет его применимость.
Старые .saprbar.json 1.0.0 открываются без этого поля как ручной ввод площадей.

Точность и параметры отчёта сохраняются при закрытии диалога в текущем сеансе.
Они не записываются в модель; перезагрузка страницы сбрасывает их. Предпросмотр,
HTML и печать используют одинаковый режим и точность. После правки модели
окончательный отчёт блокируется до пересчёта. Печать рассчитана на A4 с полями
20 мм и переносом длинных формул/таблиц.


### PDF без подписи и адреса (2026-10-11)
В диалоге РГР добавлена кнопка «PDF без подписи и адреса». PDF формируется
из самого отчёта локально через html2pdf.js, без окна печати браузера и его
колонтитулов с названием страницы и HTTPS-адресом. Учитываются текущий вид
РГР, точность и включение графики. Устаревшие результаты блокируются;
изменение настроек/модели или закрытие диалога отменяет незавершённое скачивание.
Обычная печать остаётся доступной; для неё колонтитулы отключаются пользователем
в настройках браузера. Программно сайт этой настройкой браузера не управляет.
Этот прямой PDF содержит растровые страницы; для редактирования сохранён HTML.
Визуальная проверка PDF пока недоступна без браузера. Источник API:
https://github.com/eKoopmans/html2pdf.js .


## Калькулятор сечений
В размерах, координатах и вершинах можно вводить выражения: `3a`, `2*b`,
`1,5b`, `a/2`, `(a+b)/2`. При a=38 см выражение `3a` даёт 114 см.
Под полем показывается численный результат; смена a/b пересчитывает связи.
Обычные числа остаются постоянными в режиме «Переменные для выражений».
Выражения сохраняются вместе с сечением и проектом. Рисование/перетаскивание
заменяет формулы затронутых координат или размеров обычными числами.
Старые сечения сохраняют прежний режим растяжения, пока не выбраны переменные
или не введено первое выражение. Формула хранит единицы своего ввода;
при смене единиц её смысл и текст сохраняются. Ошибки блокируют расчёт/сохранение.
Для самостоятельного чертежа нажмите «Нарисовать с нуля». Фигуры создаются
протягиванием мыши, произвольный контур — точками и командой «Замкнуть контур».
Материал и вырез выбираются перед рисованием. В режиме выбора перетаскивайте
часть или её маркеры; Delete удаляет выбранную часть при фокусе на чертеже.
Доступны сетка, привязка, увеличение и вписывание. Таблица и чертёж используют
одну геометрию. Поля a/b доступны после ручных правок: для пользовательского
сечения это опорные размеры масштабирования по x/y. Круговые части допускают
только одинаковый масштаб по осям; радиус можно изменить отдельно.
Кнопка «Сечения»: независимый выбор схемы и строки размеров, редактор частей/вырезов с координатами и поворотом, единицы мм/см/м. После изменения геометрии требуется пересчёт. Реализованы схемы 1–8, 10, 12, 15–19, 21–23, 25–30 и все 20 строк. Неподтверждённые схемы объясняют недостающие размеры.
Результаты: площадь, центр, моменты, главные оси, радиусы инерции и моменты сопротивления реальных крайних волокон. Полный/краткий отчёт: формулы, подстановки, HTML и A4. Масштабы 1:2/1:5 проверяются на размещение; автоматический режим указывает фактический масштаб. Печатайте при 100%, без дополнительного вписывания браузера.
«Сохранить сечение» создаёт .saprsection.json; «Использовать сечение в проекте» назначает сечение выбранному стержню либо добавляет в список. Требуется подтверждение оси изгиба; связанный изгиб запрещён. Геометрия сохраняется в проекте и редактируется из свойств. Старые JSON совместимы. [Формулы и ограничения](docs/section-calculator-spec.md).
