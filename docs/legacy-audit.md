# Аудит поставки SAPR-BAR 3.0

Дата исследования: 2026-10-01.

## Объект и метод

Исходный архив: `(2)SMiTM_PO_UNIVER_SETUP(27.08.2022).zip` в корне репозитория, 17 437 859 байт, SHA-256 `e870dcf4f1f18c9589e462544f36cb5c678f92166b3601bfecf6b9b4f2317eb3`. Архив предварительно проверен по списку записей: абсолютных путей, Windows-путей с буквой диска и компонентов `..` не найдено. Он распакован без перезаписи файлов (`unzip -n`) в отдельное дерево:

`legacy-extract/SMiTM_PO_UNIVER_SETUP(27.08.2022)/`

Оригинальный ZIP и его содержимое не изменялись. BAT- и EXE-файлы не запускались. Использовались только чтение метаданных, преобразование текстовых кодировок и извлечение строк из бинарников.

Уровни уверенности в этом отчёте:

- **высокая** — прямо сказано в документации SAPR-BAR или подтверждается несколькими независимыми артефактами SAPR-BAR;
- **средняя** — следует из статических строк одного или нескольких EXE, но не описано полностью;
- **низкая** — правдоподобная интерпретация имени/косвенного признака; не является спецификацией.

## Разделение продуктов

Поставка содержит три отдельных комплекса:

| Комплекс | Каталог | Наблюдаемый состав | Отношение к исследованию |
|---|---|---|---|
| SAPR-BAR 3.0 | `SAPR-BAR/` | DOS-программы, две справки MSG, DOSBox, BAT/LNK, графические ресурсы | целевой продукт |
| KIPR-Win | `KIPR-Win/` | отдельные Windows EXE, HTML-справка, примеры CN/LD/MD/MT | не источник возможностей или форматов SAPR-BAR |
| Test-Win | `Test-Win/` | отдельный Windows EXE, справочные данные, BAT/LNK | не источник возможностей SAPR-BAR |

`ReadMe.DOC` подтверждает, что это именно три программных комплекса, которые общий установщик устанавливает вместе. Наличие одноимённых расширений CN/LD/MD у KIPR-Win **не доказывает совместимость**. Примеры KIPR-Win при выводах о SAPR-BAR не использовались.

## Изученные источники

1. `ReadMe.DOC` — Word Compound Document, code page 1251. Содержит только назначение общих установщиков C/D и предупреждение о распаковке; функциональность SAPR-BAR не описывает.
2. `SAPR-BAR/FILES/HELP_30R.MSG` — 19 716 байт, 395 строк после декодирования CP866. Подробно описывает CN, LD и MD, включая сдвиг.
3. `SAPR-BAR/FILES/HELP_30B.MSG` — 18 077 байт, 369 строк после декодирования CP866. Почти тот же текст, но без массива характеристик сдвига SC и параметра SD.
4. Статические строки `BR_30.EXE`, `DR_30.EXE`, `SH_30.EXE`, `CR1_30.EXE`, `CR4_30.EXE`, `CR5_30.EXE`, `CR7_30.EXE`, `CR9_30.EXE`; файлы не выполнялись.
5. Инвентаризация `SAPR-BAR/FILES/` и чтение BAT как данных.

### Проверка CP866

Обе MSG целиком преобразуются `iconv -f CP866 -t UTF-8`. Результат содержит связный русский текст и корректную DOS-псевдографику (`╔═╗`, `║`, `╚═╝`). Это сильное содержательное подтверждение CP866. Определение `file` само по себе кодировку не назвало.

### Варианты HELP_30B и HELP_30R

`HELP_30R.MSG` расширяет запись характеристик сечения с `XC[0:9]` до `XC[0:10]`, вставляет ссылку `ISC`, массив `SC[1:NC][1:5]` и `IZ[4]=SD`. Суффиксы B/R в поставке не объяснены. Поэтому нельзя без контрольных файлов утверждать, какой вариант читает каждый расчётный модуль. Для новой модели разумно поддержать явные версии, а не пытаться автоматически смешать записи.

## Исходный код и исполняемый состав

Исходных файлов в поставке **нет**. По всему распакованному дереву не найдено файлов типичных исходных форматов (`.c`, `.h`, `.cpp`, `.pas`, `.for`, `.asm` и т. п.). Внутри `CR1_30.EXE` статически видны строки `CR010_B2.C` и `CR000_B2.H`, но соответствующих файлов нет; это остаточные имена сборки, не доступные исходники.

Целевой комплект содержит только:

- DOS EXE: оболочка `SAPR_B30.EXE`, `SH_30.EXE`, `BR_30.EXE`, расчётные модули `CR1/4/5/7/9_30.EXE`, `DR_30.EXE`;
- текстовые справки MSG;
- DOS-шрифт `FNTRSH.CHR`, BMP/ICO, BAT/LNK;
- сторонний DOSBox 0.74-2 и его файлы.

Роли EXE по именам однозначно не документированы. По строкам и составу можно осторожно считать `CR1/4/5/7/9` модулями задач с теми же номерами, `BR_30` — компонентом подготовки/просмотра, `DR_30` — компонентом результатов; уверенность средняя.

| Область | Установленное поведение | Источник | Уверенность |
|---|---|---|---|
| Расчётная модель | плоские стержневые конструкции | HELP_30R/B, §4.3 | высокая |
| Задача 01 | статический расчёт; геометрически линейный при `NL=0`, нелинейный методом Ньютона при `NL>0`; шаги параметра нагрузки; опциональный собственный вес | HELP_30R/B, §4.3.3.1 | высокая |
| Задача 04 | отклик при гармоническом возбуждении в диапазоне частот `w_0..w_k` с шагом `dw` | HELP_30R/B, §4.3.3.2 и описание амплитуд в LD | высокая |
| Задача 05 | собственные колебания, включая предварительное НДС; диапазон тонов `M_0..M_k`; `NL=-1` игнорирует LD и рассматривает ненагруженную конструкцию | HELP_30R/B, §4.3.3.3 | высокая |
| Задача 07 | динамика во времени с шагом `dt`, конечным временем `t_k`, периодом вывода `N_put`; закон нагрузки кусочно-линейный | HELP_30R/B, §4.2 и §4.3.3.4 | высокая |
| Задача 09 | поиск критического параметра нагрузки (устойчивость), линейная/геометрически нелинейная постановка по `NL` | HELP_30R/B, §4.3.3.5; строка CR9 | высокая |

| Дискретизация | промежуточные узлы на каждом стержне, автоматически или через `MS` | HELP_30R/B, §4.3.1 | высокая |
| Сечения | произвольное; кольцо/круг с круглым отверстием; прямоугольник с прямоугольным отверстием; прямоугольник с круглым отверстием | HELP_30R/B, XC | высокая |

| Временная зависимость | единый кусочно-линейный множитель `F(t)` по точкам `FT`; документация подчёркивает применение к силовым нагрузкам | HELP_30R/B, FT | высокая |

## Форматы, установленные на уровне продукта

| Имя/расширение | Наблюдаемая роль | Источник | Уверенность |
|---|---|---|---|
| CN | исходные данные конструкции | HELP_30R/B | высокая |
| LD | нагрузки и закрепления | HELP_30R/B | высокая |
| MD | методические параметры задачи | HELP_30R/B | высокая |
| CNX, LDX, MDX | формируются программой; внутреннее назначение/формат не описаны | строки BR_30 | средняя только для существования |
| KPR | «файл-проект», включает выбранные файлы; структура не дана | строки BR_30/DR_30/SH_30 | средняя |
| MT | предлагается в выборе файлов, но не объяснён в MSG | строки EXE | средняя только для существования |
| RES (`.res`) | файл результатов, версионно несовместимый между выпусками | HELP, строки DR_30/EXE | высокая для роли, неизвестна структура |
| OUT (`.out`) | упоминается компонентом результатов; вероятно текстовый вывод | строки DR_30 | низкая/средняя |
| RS0, FW | промежуточные/выходные файлы, точная роль не описана | строки EXE | средняя только для существования |
| BMP | экспорт изображения/твёрдая копия | строки BR_30/DR_30 | средняя |

Расширения без документированной структуры нельзя считать публичным API. Отдельная спецификация подтверждённой части CN/LD/MD находится в `docs/file-formats.md`.

## Ограничения исследования

- Примеров CN/LD/MD именно SAPR-BAR в поставке нет. Найденные в архиве примеры принадлежат KIPR-Win и исключены из доказательной базы.
- EXE не запускались, поэтому не получены генерируемые шаблоны, фактические файлы результатов и граничные сообщения с численными лимитами.
- Формулы конечного элемента, матрицы, соглашения о знаках, алгоритмы интегрирования и нормирования форм колебаний в поставке отсутствуют.

## Дополнительные PDF-эталоны

В каталоге `primer/` обнаружены учебные отчёты со скриншотами интерфейса именно «САПР-BAR v3.0». Они подтверждают фактический B-вариант `XC[NC,0:9]`, расположение массивов CN/LD/MD, использование SI в показанных работах и единичное состояние параметра нагрузки `q_0=q_k=dq=1`. Это визуальные транскрипции, а не сами исходные файлы: некоторые страницы сделаны в разные даты и отдельные исходные/результирующие значения внутри отчётов противоречат друг другу. Поэтому каждая численная строка используется как эталон только после проверки внутренней согласованности.
- Размерности всех входных и выходных величин не указаны в исследованных текстах.
- Лицензия/право на перенос алгоритмов SAPR-BAR в поставке не обнаружены; `COPYING.txt` относится к DOSBox, а не к SAPR-BAR.
