# Независимая верификация линейно-статического ядра

Эталонные значения ниже получены из закрытых аналитических решений сопротивления материалов и уравнений глобального равновесия. Они не вычисляются матрицами или функциями production solver-а. Тесты находятся в `src/solver/solve.test.ts`.

Для ненулевого ожидаемого значения проверяется

```text
|actual−expected| ≤ max(absTol, relTol·|expected|),  relTol=1e−9.
```

Относительный допуск `1e−9` заметно больше накопленной ошибки binary64 для малых тестовых систем, но достаточно строг, чтобы обнаружить ошибку знака, коэффициента, длины или преобразования. Около нуля используется указанный абсолютный допуск, поскольку относительная ошибка там не определена.

## 1. Осевое растяжение

Прямой стержень: `E=200 GPa`, `A=0.01 m²`, `L=2 m`, `P=100 kN`. Поперечные/вращательные DOF конца закреплены, чтобы тестировать только осевую часть.

Из закона Гука для призматического стержня:

- `u_j=PL/(EA)=1.0e−4 m`;
- реакция `Rx_i=−P=−100000 N`;
- `N=P=100000 N` по длине.

Допуски: `1e−14 m` для перемещения и `1e−7 N` для сил.

## 2. Консоль с силой на конце

`E=210 GPa`, `I=8e−6 m⁴`, `L=3 m`, сила `P=1000 N` вниз на свободном конце. Классическое решение балки Эйлера—Бернулли:

- `v_j=−PL³/(3EI)=−0.005357142857… m`;
- `θ_j=−PL²/(2EI)=−0.002678571428… rad`;
- `Ry_i=P=1000 N`;
- `Mz_i=PL=3000 N·m`;
- эпюра в заделке по принятому знаку `M(0)=−PL`.

Допуски: `1e−12` для перемещений/угла, `1e−8` для сил/моментов.

## 3. Балка на двух опорах под равномерной нагрузкой

Один элемент длиной `L=6 m` с двумя освобождёнными концевыми вращениями; `qy=−w`, `w=2000 N/m`. Одна опора фиксирует X/Y, вторая — Y. Из равновесия и известной параболы моментов:

- `Ry_i=Ry_j=wL/2=6000 N`;
- `M(0)=M(L)=0`;
- `M(L/2)=wL²/8=9000 N·m`;
- `v(L/2)=−5wL⁴/(384EI)=−0.003375 m`;
- освобождённые концевые действия `p_mi=p_mj=0`.

Допуск `1e−8` N или N·m. Проверка средней точки непосредственно подтверждает, что распределённая нагрузка учтена при восстановлении усилий внутри элемента, а не только в узлах.

Для консоли с равномерной нагрузкой `w=1000 N/m`, `L=3 m`, `E=210 GPa`, `I=8e−6 m⁴` прогиб свободного конца проверяется по `v(L)=−wL⁴/(8EI)=−0.006026785714285714 m`; полевое перемещение на конце совпадает с узловым.

## 4. Наклонный элемент

Консольный элемент между `(0,0)` и `(3,4)`, то есть `L=5 m`, `c=3/5`, `s=4/5`. Сила `P=50 kN` приложена строго вдоль локальной оси: `[Fx,Fy]=[Pc,Ps]`. Аналитически `δ=PL/(EA)`, поэтому:

- `Ux_j=δc`;
- `Uy_j=δs`;
- `Rz_j=0`;
- реакции `Rx_i=−Pc`, `Ry_i=−Ps`.

Допуски `1e−13 m/rad` и `1e−7 N`. Тест независимо контролирует обе стороны преобразования координат.

## 5. Глобальное равновесие

Для портальной рамы из файлового примера суммируются все узловые нагрузки, результирующая равномерной нагрузки в середине элемента и реакции с их моментами относительно глобального начала координат. Ожидается:

- `ΣFx=0`, абсолютный допуск `1e−6 N`;
- `ΣFy=0`, абсолютный допуск `1e−6 N`;
- `ΣMz=0`, абсолютный допуск `1e−5 N·m`;
- нормированный остаток `<1e−10`.

Эталон — фундаментальные уравнения равновесия, не внутренний вектор элемента.

## 6. Неустойчивая конструкция

Свободный в пространстве один рамный элемент с осевой силой имеет три жёстких перемещения. Ожидается отказ `MECHANISM_OR_SINGULAR`, без перемещений, реакций и частичных результатов. Численного эталона нет: критерий — корректная классификация вырожденной системы.

## Что эта проверка не доказывает

Набор проверяет выбранную новую модель Эйлера—Бернулли. Он не доказывает совпадение с DOS SAPR-BAR, потому что отсутствуют эталонные входные и выходные файлы оригинала и описание его численного алгоритма.
