Проверка: 2026-10-06. Источник — статически извлечённые CP866-строки
DR_30.EXE и BR_30.EXE из оригинального архива SAPR-BAR.
Исполняемые файлы не запускались.

В DR_30.EXE найдены пункты «ПОСТПРОЦЕССОР», «Представление результатов
в виде эпюр», «Эпюры Nx, Qy, Mz для стержня», «Эпюра Nx для стержня»,
«Эпюра Qy для стержня», «Эпюра Mz для стержня», «ЧИСЛОВЫЕ ЗНАЧЕНИЯ
на эпюрах», «Масштаб ЭПЮР». HELP_30B/R.MSG прямо упоминают просмотр
файлов результатов расчёта в постпроцессоре. Это подтверждает наличие
режима эпюр; точная геометрия интерфейса и знаки по этим строкам
не установлены. В меню также присутствуют перемещения и напряжения;
эта доработка добавляет самостоятельные графики усилий Nx/Qy/t.

## Поведение веб-версии

После успешного расчёта в результатах появляется блок «Эпюры по стержням».
По умолчанию показаны все стержни, для каждого — отдельные Nx, Qy, Mz.
Можно выбрать один стержень, изменить визуальный масштаб ординат,
скрыть числовые подписи и скачать три графика стержня одним SVG.
Подписи показывают концы и минимум/максимум среди расчётных точек;
наведение на точку выдаёт её x и значение. Подписаны номера стержня,
узлов i/j, длина и единицы. Нулевая эпюра явно отмечена.

Графики берутся из настоящего результата расчёта. x — локальная
координата от i к j; положительные значения выше оси. Масштабы графиков
независимы, что подписано рядом. Это решение веб-версии, а не заявленная
копия оригинального представления. Численные значения и знаки solver-а
не менялись. Графики используют существующую дискретизацию ядра (21 точка);
экстремумы между этими точками отдельно не вычисляются.

В печать входят все Nx/Qy/Mz при актуальном успешном результате.
При изменении модели неактуальные эпюры скрываются и в UI, и в печати.
Тесты проверяют графики Иванова, SVG-координаты промежуточной точки,
единицы, нулевые эпюры, подсказки, печать и скрытие неактуальных графиков.
