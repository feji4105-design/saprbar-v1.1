# Пошаговый осевой отчёт РГР

Режим является самостоятельным представлением веб-версии. Он применяется
к одной прямой цепочке участков с одной или несколькими осевыми опорами,
без поперечных сил, моментов и распределённых нагрузок. Перед построением
проверяются геометрия, связность, опора, нагрузки и постоянство N из результата.
Для рам, поперечных и распределённых нагрузок осевой вывод не выполняется;
доступен обычный табличный отчёт.

Источник формул: равновесие отсечённой правой части, закон Гука и связь
продольной деформации с перемещением. Положительное направление x — от начала выбранной цепочки. Для правой отсечённой части положительное растягивающее
N направлено влево: −N + ΣFсправа + ΣRсправа = 0, N = ΣFсправа + ΣRсправа.
R = −ΣF; σ=N/A; ε=σ/E; du/dx=ε; Δℓ=Nℓ/(EA) при постоянных N,E,A.
Совместность между участками: uкон,i=uнач,i+1; u=0 в каждой осевой опоре.
Единицы подстановки деформаций: N, мм, Н/мм² (=МПа), мм² → мм.
Реакция для единственной опоры определяется равновесием; дополнительные
условия совместности для неё не нужны.

При A_i=k_i Aбаз условие прочности даёт
Aбаз,min=max_i |N_i|/(k_i[σ]_i), с отдельными допусками растяжения/сжатия.
Проверка жёсткости: max |u|≤[u]. В кусочно-линейной эпюре u экстремумы
находятся в узлах. Для отчёта используются проекции рассчитанных перемещений
на ось стержня, а Δℓ независимо вычисляется по формуле выше.
Без подтверждённого E и заданного [u] успешный вывод о жёсткости запрещён.
Глобальные допуски задаются пользователем в МПа; одинаковые ненулевые
Sp/Sc всех XC берутся из legacy-происхождения после пересчёта выбранных единиц.
Эти критерии не меняют материал или сечения модели.

## Проверки

RgrReport.test.tsx проверяет каждый N/σ на всех расчётных точках,
реакцию, каждый интеграл перемещения, эквивалентность CN/LD/MD и JSON,
условность проверки жёсткости, успешный и неуспешный вывод при явных допусках,
скрытие старых графиков, неприменимость к рамам и двум опорам.
При удвоении E перемещения уменьшаются вдвое, N не меняется.
Схема проекта и solver не изменены; schemaVersion остаётся 1.0.0.

## Свободный ввод и подбор площадей

Подбор базовой площади использует фактически рассчитанное ядром N_i
и отношение каждой ступени k_i: A₀,min=max |N_i|/(k_i[σ]_i).
Единицы: N в Н, допускаемое напряжение в МПа → площадь в мм².
При нескольких заделках силы определяются с учётом совместности в solver.

Для подбора сначала строится модель с A₀=1 мм² и введённым E. В чисто
осевой цепочке K_axial масштабируется пропорционально A₀. При всех
предписанных осевых перемещениях, равных нулю, u пропорционально 1/A₀,
а N=EA(u_j-u_i)/L не зависит от общего масштабного множителя A₀.
Это позволяет использовать полученные N для подбора общей базовой площади
как при одной, так и при нескольких заделках. Для отсутствия деформаций
вообще (все силы приложены только к закреплённым узлам) минимальная
ненулевая площадь не определяется; она задаётся вручную.

Тесты проверяют RGR1: A4,A1,A3,A2, N=160,70,-10,-60 кН,
uкон=.9875 мм при A₀=1000 мм², E=80 ГПа. Дополнительно проверяются
12 ступеней, вставка без потери нагрузок, объединение узлов при удалении ступени,
правая и внутренняя заделки, силы на левом конце, восстановление из JSON.
Независимый эталон двух одинаковых участков между двумя заделками:
при средней силе P реакции −P/2, N_left=+P/2, N_right=−P/2,
u_mid=PL/(2EA), u концов=0. Этот эталон проверяет совместность и подбор A₀.

## Изменение длин и разбиение

При разбиении однородного участка на две равные части суммарная осевая
податливость L/(EA) сохраняется: (L/2)/(EA)+(L/2)/(EA)=L/(EA).
Без новой средней силы/опоры сохраняются N, реакции и перемещения исходных
узлов. Это проверено сравнением полного расчёта до и после разбиения.
При общем масштабировании всех длин в c раз в осевой задаче с силами
и нулевыми закреплёнными перемещениями реакции и N неизменны, а u
масштабируются в c раз; соответствующий тест использует c=2.
Направление штриховки — исключительно настройка изображения.


## РГР с несколькими заделками
Для прямой цепочки с узловыми осевыми силами число осевых закреплений m
не ограничено двумя. Степень статической неопределимости равна m−1.
Система: ΣR+ΣF=0 и, между каждой парой соседних закреплений,
ΣNᵢℓᵢ/(EᵢAᵢ)=0. При правом отсечении Nᵢ включает нагрузки и реакции
справа. Коэффициент реакции в условии совместности — сумма ℓ/(EA)
для тех участков данного пролёта, справа от которых находится эта опора.
Все закрепления имеют нулевые заданные перемещения. Проверяются интегралы
деформаций, нулевые перемещения опор и равновесие сечений.
Численный эталон: два пролёта по 2 м, одинаковые EA, силы 10 и 20 кН
в серединах; реакции −5, −15, −10 кН, N=5, −5, 10, −10 кН.
Тесты также покрывают 2, 4 и 5 заделок с переменными площадями.
Таблицы результатов используют номера объектов, отдельную прокрутку и
раскрывающиеся блоки; таблица концевых действий занимает полную строку.


## Краткое представление и точность (2026-10-11)
Используются те же полные N, σ, Δℓ и u, что в полном отчёте. Форматирование
запускается после проверки и не участвует в сравнениях |σ|≤[σ], |u|max≤[u].
При внутренней первой опоре начальное перемещение вычисляется из
u(0)=uопоры−ΣΔℓ до этой опоры; далее uкон=uнач+Δℓ. Подстановка реакций в
условия совместности проверяет исходную систему. Принятые площади и минимально
требуемые показываются отдельно. Общий масштаб площадей не изменяет N при
нулевых предписанных перемещениях, в том числе для нескольких заделок.
Факт команды подбора фиксируется с точным снимком расчётных данных;
без действительного снимка вычисление минимальных требований называется
проверкой принятого сечения. Настройка количества знаков не меняет снимок.
