## Отчёт по образцу

В списке видов отчёта добавлен «По образцу РГР1 (7 шагов)» без титульного листа:
дано → силы → соотношение площадей → условия прочности → принятые площади →
напряжения → деформации → перемещения → схема и три эпюры. Обозначения
A1/A2/A3/A4 берутся из названий сечений, а не выводятся из номера участка.
Числа вычисляются по текущей модели; статические ответы не вшиты.
Условие прочности выбирается по знаку N. При отсутствии допуска выводится
невозможность полной проверки. Изменение допусков не подбирает площади автоматически.
Подбор показывается как выполненный только при актуальном metadata.areaSizing.
Формат ограничен одной концевой заделкой и поддержанной прямой осевой цепочкой.
Для остальных схем доступны прежние отчёты, ограничение нового вида объясняется.

Это воспроизведение структуры и содержания образца в HTML/PDF, не побайтовое
копирование Word-разметки и не экспорт DOCX. Обычная печать, прямой PDF,
HTML, точность, включение графики и блокировка устаревших результатов сохранены.
Пагинация приложения — A4, исходный DOCX задаёт Letter. LibreOffice в среде
не установлен, поэтому визуальная идентичность исходному Word не проверена.

`node scripts/generate-rgr19.mjs` воспроизводит JSON и HTML в
`output/rgr19-variant4/`. E для готового HTML подтверждён чтением формул
DOCX; при открытии JSON в приложении флаг подтверждения E по умолчанию снят.
`AssignmentRgrReport.test.tsx` проверяет фотографическое соответствие, независимую
осевую аналитику, минимальную площадь, баланс, семь шагов, ссылки на площади,
пересчёт изменённой нагрузки, пропущенные допуски, графику и устаревшие результаты.
Ядро solver не менялось.
