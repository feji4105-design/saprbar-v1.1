# Проверка Иванова, 2026-10-06

Скриншот согласуется с ошибочным выбором мм/кН/МПа для данных,
которые по масштабу координат, E=0.8e11 и сил 60e3 соответствуют SI.
Это вывод из входных значений, а не подтверждение исходного выбора в браузере.
При неверном профиле координаты сжимаются в 1000 раз, силы растут в 1000 раз,
а модуль E растёт в 1e6 раз. Автовписывание само по себе единицы не исправляет:
уже импортированную модель нужно импортировать заново с SI.

В tests/fixtures/ivanov-corrected сохранён исправленный комплект. Исправления
и независимая аналитика описаны в его README.md. Вариант квадратных сечений
выбран по GOLOVORO.CN; у GOLOBORO.CN другая ширина, поэтому окончательное
соответствие учебному заданию следует сверить с условием.

Расчётное ядро не изменялось. Тест ivanov.test.ts сравнивает все точки N/Q/M,
реакцию и перемещения с аналитикой. SchemeCanvas.test.tsx проверяет
положение крайних узлов, замыкание эпюр и обязательный выбор единиц.
Полный npm run check включает существующие тесты аналитики,
суперпозиции и сравнения с независимыми эталонами.
Живая проверка браузера не проводилась; SVG проверен через React SSR.
